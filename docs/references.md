# Yamaha's documents

The notes in this folder quote Yamaha's manuals for the reface. They are
Yamaha's copyright and are not kept in this repository. Yamaha offers them
for download:

- **reface Data List** (`reface_en_dl_b0.pdf`): the MIDI implementation
  chart and the SysEx parameter tables, including the system parameter
  addresses used throughout `menu-internals.md`.
- **reface Owner's Manual** (`ZT92080_reface_En_OM_C0.pdf`): Function mode
  and the DATA ENTRY switches. It does not describe Update mode.
- **reface Reference Manual** (`reface_en_rm_a0.pdf`).
- **reface DX v1.30 Supplementary Manual** (`v130_Manual_en.pdf`): the
  FUNCTION pages as numbered in firmware v1.30.
  https://data.yamaha.com/files/download/other_assets/0/960060/v130_Manual_en.pdf
- **reface CS/DX Updater Guide** (`UpdaterGuide_en.pdf`): inside the
  updater zip, next to the app.

All of them are in Yamaha's manual library: search for "reface" at
https://usa.yamaha.com/support/manuals/ . The updater zip is at
https://usa.yamaha.com/support/updates/reface_csdx_updater_for_mac.html .
