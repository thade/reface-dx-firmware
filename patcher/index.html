reface DX clock switch
Source

Turn off the MIDI clock on your reface DX.

This page turns Yamaha's own reface CS/DX firmware v1.30 into a version with a MIDI clock switch in the FUNCTION menu, right here in this browser tab, and can send it to the DX. Nothing is uploaded, and the page contains none of Yamaha's firmware.

What it does

The reface DX always sends MIDI clock, and Yamaha gives no way to stop it. This firmware adds a sixth FUNCTION page, MIDI 2, with one item, CLOCK. When CLOCK is off the DX sends no clock. Everything else works as before, and the DX keeps the setting when it is switched off.

MIDI 2 ◇◇◇◇◇◆ CLOCK ON

To reach the page, press FUNCTION until MIDI 2 shows. To switch, tap the leftmost DATA ENTRY switch. A version with the clock permanently off is also offered below.

1

Download Yamaha's reface updater v1.30

On Yamaha's support site, download the reface CS/DX updater v1.30 for Mac. You get reface_updater_CSDX_v130-3_mac.zip; keep it zipped, you don't need to open it.

Yamaha's reface CS/DX updater page →

The updater for the CS and DX, not the one for the CP and YC. Use the Mac download even on Windows. The page only reads the zip, and the Windows download has not been tried.

Before you install
  • This is unofficial firmware, not made or supported by Yamaha. It replaces the main firmware of your DX.
  • The DX's update program is never changed, so you can put Yamaha's firmware back the same way if anything goes wrong. This has been done.
  • Yamaha's licence does not allow changing its firmware without permission. Installing this is your decision and your responsibility.

3

Put the DX into Update mode

  1. Power the DX from its AC adaptor, not from USB, and connect it to this computer by USB, with no hub in between.
  2. Close any music software that uses the DX.
  3. Switch the DX off. Hold the keys F#3, A3 and C#4 together and switch it on. The display reads reface DX Update. If it starts normally instead, switch off and try again.
4

Send it to the DX

The browser will ask permission to talk to the DX (it calls this "MIDI access"): allow it. The transfer takes about three minutes. Don't touch the DX or the cable until its display says Completed.

Download the firmware file

It is a Standard MIDI File of 139 SysEx messages, 2,250,052 bytes, in the same format as Yamaha's reface updater.dat. Any SysEx tool that keeps the file's own timing (about 1.4 seconds between messages) can send it to the DX in Update mode. On a Mac you can also put it in a copy of Yamaha's updater app in place of its Contents/Resources/reface updater.dat and re-sign the app with codesign --force --deep --sign - "reface updater.app".

5

Finish on the DX

  1. Wait until the display reads Completed. 1.30 --> 1.30 Reboot. If it stops at a percentage, switch the DX off, enter Update mode again and send again from step 3.
  2. Switch the DX off and on with its Standby/On switch.
  3. Press FUNCTION until MIDI 2 shows, and tap the leftmost DATA ENTRY switch to set CLOCK off. Leave FUNCTION by pressing any other button, so the DX saves the setting.

Your voices and settings stay. To go back to Yamaha's firmware, run Yamaha's own updater the same way, from Update mode.
